# 🛍️ Sybug Store

A modern, premium e-commerce storefront demo built with **HTML, CSS, and JavaScript**.

Sybug Store is designed as a concept online marketplace combining **tech gadgets, fashion, and home essentials** into a clean luxury-inspired shopping experience.

## ✨ Demo

**Sybug Store — Live Different. Shop Bold.**

> Tech, fashion & home essentials — curated for the ones who don't settle.

## 🚀 Features

* 🌓 Dark / Light mode
* 🛒 Interactive shopping bag/cart counter
* 🛍️ Product listing system
* 🔔 Add-to-cart notifications
* 📱 Responsive design
* ✨ Premium minimalist UI
* 🎨 Gold luxury-inspired accent theme
* ⚡ Smooth scrolling and hover animations
* 📧 Newsletter subscription UI
* 📦 Product categories:

  * Tech Gadgets
  * Fashion
  * Home Essentials

## 🧰 Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript**
* Google Fonts

  * DM Sans
  * Playfair Display

* Minimal card layouts
* Glassmorphism-inspired navigation
* Smooth micro-interactions

## ⚠️ Demo Status

This project is currently a **front-end demo / concept project**.

The following features are not connected to a real backend yet:

* Real product database
* User authentication
* Real checkout
* Payment gateway
* Order management
* Inventory management
* Backend APIs

The cart and newsletter functionality are currently simulated using JavaScript.
